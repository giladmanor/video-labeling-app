    The key is the keyboard shortcut on the labeling screen: it sets the label of the selected segment. Use one character that is not already a key there (). The background label (0) is what watched time with no segment gets, and what a rejected suggestion becomes. Ignore (−1) is not used for training. The first event label is the one that Accept, P, and Start/End make. A new label gets a color that no other label uses; click the color to choose another one. A label that is in use in a label file cannot be removed.

    Keys

    Spaceplay / pause
    ← →one frame back / forward
    Shift+← →one second back / forward
    [ ]slower / faster (0.5x to 4x)
    N / Shift+Nnext / previous suggested event, played with 2 s before and 1 s after
    Aaccept the suggestion ()
    Rreject the suggestion (, hard negative)
    Uignore, −1 (the suggestion, or the selected segment)
    P (hold)mark while the key is down (the Hold buttons mark any label)
    I / Oset the start / end of the selected segment (or of a new event segment)
    Deletedelete the selected segment
    T then 1–8toggle a tag on the selected segment
    Wplay the next unwatched part
    Bplay a random unwatched part (for normal examples)
    ⌘+Zundo
    Entermark the video done, open the next one (click the status to reopen)
    Shift+Sskip the video (the note is the reason)
