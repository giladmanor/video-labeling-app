    Keys

    Spaceplay / pause
    ← →one frame back / forward
    Shift+← →one second back / forward
    [ ]slower / faster (0.5x to 4x)
    N / Shift+Nnext / previous suggested event, played with 2 s before and 1 s after
    Aaccept the suggestion (phone)
    Rreject the suggestion (driving, hard negative)
    Uignore, −1 (the suggestion, or the selected segment)
    1 / 0set the selected segment to phone (1) / driving (0)
    P (hold)mark phone while the key is down
    I / Oset the start / end of the selected segment (or of a new phone segment)
    Deletedelete the selected segment
    T then 1–8toggle a tag on the selected segment
    Wplay the next unwatched part
    Bplay a random unwatched part (normal driving)
    ⌘+Zundo
    Entermark the video done, open the next one (click the status to reopen)
    Shift+Sskip the video (the note is the reason)
    Escclear the selection

    The start of a phone segment is the first frame where the event is visible: the phone is in view in the hand, or the hand clearly moves to take it.

    Only watched time is exported. Watched time with no segment becomes "driving".
